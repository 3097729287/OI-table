# OI-table 全局界面与首页工作台设计约定

主窗口中的工作台、设置页和新增业务视图统一采用**紧凑、平面、分区清晰的桌面工具界面**。下文的视觉、主题和动效规则适用于应用界面，三栏布局和标签行为适用于首页工作台。

## 全局视觉风格

- **用布局表达层级。** 窗口用连续的底色划分导航和内容，同一面板内用标题、对齐和留白分组，相邻窗格用 1px 分隔线。题库列表适合用紧凑的行，设置项适合用标签与控件对齐的表单行。大面积渐变、投影和逐项卡片化都不作为常规界面样式。
- **形状与任务相配。** 窗格、标签栏和导航轨保持直边，让可拼接的区域自然相接。局部控件沿用小圆角，例如标签关闭按钮 3px、编辑框 4px、设置表单控件 5px、上下文菜单 6px。图标复用单色 `Icon`，通过 `currentColor` 与文字同步反馈。
- **让操作位置一眼可辨。** 大面积保持中性色，强调色集中用于当前项、焦点窗格和拖放目标。选中同时配底线、侧线或选中底色，键盘焦点保留独立轮廓。产品插画可以使用渐变与多色，常规控件沿用语义色。
- **按阅读任务分配空间。** 工具栏和导航保持紧凑，正文与表单留出阅读间距。界面沿用系统无衬线字体，代码编辑区使用等宽字体。新增页面先复用同类页面的标题、行高和间距，具体数值见下文。

## 全局动效

动效用来说明哪一项发生了变化、内容移到了哪里。按下和悬停只改变控件本身，切换面板只过渡进入的内容，拖动时位置跟随指针。新组件按下表选择最接近的场景，并显式列出参与过渡的 CSS 属性，避免 `transition: all`、弹跳、过冲和循环装饰动画。

| 使用场景 | 应采用的效果 | 时长与缓动 |
| --- | --- | --- |
| 按下、悬停 | 按下改变底色，松开回到悬停态。上下文菜单项按下 45ms、悬停 90ms。 | 短反馈用 `ease-out`。工作台导航和标签沿用所在区域的 180ms 过渡。 |
| 打开上下文菜单 | 整个菜单从 `scale(0.96)` 到原尺寸，菜单项立即可操作。 | 125ms，`cubic-bezier(0.2, 0.75, 0.25, 1)` |
| 工作台切换与布局 | 首个窗格直接占满内容区。展开或收起侧栏时过渡列宽，窗格重排时过渡位置和尺寸。切换标签时，进入的面板透明度从 0.5 到 1，底线在标签内从底边升起。 | 复用 `--workspace-motion`，即 180ms，`cubic-bezier(0.2, 0.75, 0.25, 1)` |
| 侧栏分组 | 展开或折叠时过渡子列表高度。首次读取完成后展开，折叠时保留已加载的题目和子分组。 | 复用 `--workspace-motion`。 |
| 标签改变顺序 | 相邻标签沿横轴从旧位置移到新位置，让用户看清落点。 | 150ms，`ease-out` |
| 拖动调宽、减少动态效果 | 拖动侧栏时直接更新宽度。系统启用减少动态效果时直接呈现最终位置、选中标记和焦点。 | 持续调宽时关闭列宽过渡。减少动态效果时工作台令牌取 `0ms linear`，右键菜单仅在 `prefers-reduced-motion: no-preference` 下开启动效，JS 标签重排也检查系统偏好。 |

目前 `--workspace-motion` 定义在 `.workbench` 内。新窗口采用表中同类场景的参数；需要跨窗口共用的动效变量应定义在 `:root`，组件内保留减少动态效果的处理。

## 布局与信息层级

| 区域 | 职责与基线 |
| --- | --- |
| 标题栏 | 高 32px，承载窗口标题、侧栏开关和窗口控制。窗口级操作放在这里，页面操作留在所属视图。 |
| 导航轨 | 固定宽 52px。题库、归档、收藏、提交记录、设置从上到下排列，使用 24px 图标，按钮至少高 50px。 |
| 侧栏 | 展示当前分类的分组和视图入口。默认宽 200px，可收起或调宽，上限取 420px 与工作台宽度 45% 中的较小值。常规下限为 128px，极窄时随上限收缩。分组每级缩进 12px，最小行高取 `--sidebar-row-height`（默认 26px）。 |
| 内容区 | 占满剩余空间。选中侧栏入口后打开标签，再次打开同一视图时定位到已有标签。每个窗格都有自己的 38px 标签栏，内容独立滚动。 |

初始进入时，题库侧栏展开，内容区居中显示透明背景的产品插画，最大宽度 640px。关闭最后一个标签也回到这里。插画中的淡紫、薄荷绿用于描绘题库和编辑场景。业务视图打开后，在标题下展示当前加载、空结果或加载失败的状态。

点击「设置」切换到对应的二级侧栏。外观、编辑器、运行与调试、数据与诊断共用一个「设置」标签。在侧栏切换分组会激活现有设置标签所在的窗格。切换分组或关闭标签时会提交待保存的有效数值。设置页沿用工作区的切换动效、关闭、拖动和分屏操作。

每个页面在自己的 `workspaceView` 声明 `id`，`variants` 声明带参数的侧栏入口。工作台用 `open({ id, params })` 打开视图，并将视图 ID 和参数传给页面。普通视图由 ID 和参数共同标识标签，重复打开同一组参数会定位到已有标签。动态题目、标签和目录可通过可选的 `label` 提供双语标签名，视图的 `title` 用作默认显示文字。

「题库」的「全部题目」点名称打开总表，点箭头查看标签分组和未添加标签的题目入口。「归档」的「题库归档」按库显示目录树，目录右侧显示该目录及所有子目录的题目总数。点目录名称打开对应范围的题单，点箭头展开直属内容。侧栏按需加载题目，题目列表支持按标题或 ID 搜索与分页。侧栏和列表打开同一道题时共用一个题目标签。

「设置 → 外观 → 界面语言」默认跟随系统，也可选择简体中文或 English。切换后保留已打开的标签与编辑内容。

设置通过 `update_settings` 发送本次修改的键值，由 Rust 合并写入 `settings.json` 并通知其他窗口。后端对注册了规则的键进行校验，缺失或无效时使用该键的默认值。界面以 `get_settings` 返回的值为准。

## 主题配色与自定义

应用的浅色和深色基础值、派生色一起定义在全局 `:root`，组件通过 CSS 变量取色。窗口将主题写到根元素的 `data-theme`。浅色和深色选项固定 `color-scheme`，跟随系统与薄荷绿按系统模式选择 `light-dark()` 中的对应值。 [全局配色](../src/theme/colors.css)

| 区域 | 颜色变量 | 使用位置 |
| --- | --- | --- |
| 基础底色 | `--window-background`、`--navigation-background`、`--sidebar-background` | 内容区、编辑器、活动标签、标题栏、导航轨、二级侧栏、浮层和题面代码块 |
| 文字与操作 | `--text-color`、`--muted-color`、`--accent-color`、`--accent-hover`、`--accent-pressed` | 正文、图标、次要信息、主要按钮、操作反馈 |
| 边框与导航状态 | `--control-border`、`--workbench-border`、`--navigation-hover`、`--navigation-selected` | 输入框、窗格分隔线、题目列表、侧栏、菜单与下拉选项 |
| 标题栏 | `--title-bar-color`、`--title-bar-hover`、`--title-bar-close-hover`、`--title-bar-close-color` | 窗口标题、窗口按钮、标签与菜单项悬停 |
| 工作台与题目工具栏 | `--workbench-accent`、`--workspace-rail-*`、`--tab-*`、`--split-preview-background`、`--problem-toolbar-background` | 导航轨指示条与光晕、标签栏与插入位置、内外分屏预览、题目内部标签栏 |
| 浮层 | `--floating-surface-border`、`--context-menu-pressed-background`、`--popover-shadow-*`、`--personal-dialog-*` | 右键菜单、收藏浮层、变量提示、收藏组编辑和删除弹窗 |
| 题库管理与收藏 | `--library-*`、`--favorite-*` | 导入弹窗、拖放区、选择项、错误提示和通知阴影，收藏星星、复选框和分隔线 |
| 编辑器语法与交互 | `--code-syntax-*`、`--code-editor-caret`、`--editor-*` | C++ 和 Python 语法色、光标、选区、活动行、括号、代码片段、补全、诊断波浪线和警告选中态 |
| 调试 | `--breakpoint-*`、`--debug-position-color`、`--debug-current-line-background`、`--debug-variable-*` | 断点、暂停位置、当前行底色、变量类型与变化高亮 |
| 状态与自检 | `--error-color`、`--success-color`、`--warning-color`、`--run-debug-badge-background` | 错误信息、运行与调试自检结果、任务状态 |
| 滚动条与高对比度 | `--scrollbar-thumb-*`、`--system-*` | 普通、悬停和拖动滑块，以及系统强制配色时的滑块、收藏复选框和焦点 |
| 首页插画 | `--workbench-empty-image-filter`、`--workbench-empty-image-dark-filter` | 工作台空页插画的主题滤镜。插画和应用图标各自保留素材配色 |

修改所有主题共用的基础色时，编辑 `colors.css` 中相应的 `light-dark(浅色值, 深色值)` 或派生变量。增加主题时，单独建一个 CSS 文件，用 `:root[data-theme="主题 ID"]` 覆盖需要变化的变量，并在主入口按基础配色、主题覆盖的顺序导入。需要跟随系统的主题继承基础文件的 `color-scheme: light dark`。 [全局配色](../src/theme/colors.css) · [窗口入口](../src/main.tsx)

设置中可选的主题还需登记主题 ID 和中英文名称，并加入设置保存时允许的值。组件里的状态选择器负责切换语义变量，普通图标随所在控件的文字色变化。 [主题选项](../src/features/settings/appearance/section.tsx) · [可选值](../src/shared/settings.ts) · [设置校验](../src-tauri/src/settings.rs)

输入框和下拉按钮的尺寸由 `--control-width` 与 `--control-height` 管理，默认宽 160px、高 36px。自绘滚动条的滑块为 2px，上下或左右各加 3px 操作区域。 [基础样式](../src/app.css) · [滚动条样式](../src/shared/ui/scrollbar.css)

每层内容明确一个实际滚动视口。题目面板外壳负责裁切，题面、编辑器和运行结果各自负责内容滚动。长代码块和表格可以拥有独立的横向视口。验收时缩窄窗格并使用长题面、溢出的标签和编辑器弹层，确认滚轮、键盘和自绘滑块仍可操作，实际视口的 `scrollbar-width` 为 `none`。

薄荷绿主要覆盖底色、文字、强调色和编辑器选区。按钮悬停、导航指示条和分屏预览等派生色会随基础色计算。下面是主题覆盖的写法。 [薄荷绿配色](../src/theme/mint.css)

```css
:root[data-theme="mint"] {
  --accent-color: light-dark(#17645b, #86d8c9);
  --navigation-selected: light-dark(#cdebdc, #335448);
}
```

导航轨当前分类的底色由 `--workspace-rail-selected-background` 控制，默认将工作台强调色按 11% 混入导航背景。修改后在浅色和深色下检查首页与设置页的选中态、活动标签、拖放预览和键盘焦点。

### 排版与间距

「设置 → 外观」与「设置 → 编辑器」共用系统默认、微软雅黑、衬线和等宽字体预设。系统默认字体沿用 Segoe UI、Microsoft YaHei 和系统无衬线字体。界面基准字号为 12–20 px，默认 16 px，通过 `--ui-font-size` 按比例调整界面文字。默认字号下，工作台页面与设置分组的标题均为 20px，侧栏文字 13px，标签标题 12px。页面内边距用 `--space-lg`（24px），内容分隔用 `--space-md`（16px），图文间距用 `--space-sm`（8px）。首页二级侧栏和设置分组入口复用 15px 的 `Icon`，图标随文字颜色变化。长标签单行省略，保留完整名称供悬停和辅助技术读取。

编辑器默认使用等宽字体和 13 px，字体与字号可以分别跟随界面。自定义字号为 8–40 px，切回自定义时恢复上一次保存的字号。编辑区使用 `--editor-font-family` 和 `--editor-font-size`。

## 状态与交互

| 场景 | 约定与判断依据 |
| --- | --- |
| 当前分类 | 点击导航轨按钮会展开对应侧栏。侧栏可见时，该分类设为 `aria-pressed="true"`，使用工作台强调色和导航轨选中底色。收起侧栏后取消按下态。 |
| 分组与入口 | 分组用字重 600 和箭头方向表达展开状态，并同步 `aria-expanded`。侧栏用 `aria-current` 标记最近点选的入口，以选中底色配强调色文字。直接切换标签时，侧栏仍保留上次点选位置。 |
| 活动标签与焦点窗格 | 各窗格的选中标签始终沿用内容底色。标题、图标和底线在焦点窗格使用强调色，在失焦窗格使用次要文字色。未选中标签沿用标签栏底色，隐藏底线。指示线绝对定位在标签底边，高 2px。键盘焦点保留独立轮廓。 |
| 标签操作 | 左右方向键切换，Home / End 定位首尾，Delete 关闭，Shift + F10 打开操作菜单。关闭按钮在选中、悬停或焦点进入标签时出现，无悬停设备上常显。菜单中无可执行效果的操作保留位置并禁用。 |
| 标签拖放 | 被拖标签降至 55% 不透明度。标签之间用 2px 插入线，移入目标窗格用内描边，分屏用覆盖预计区域的半透明预览。移动已打开的视图时保留草稿和滚动位置。 |
| 分屏排列 | 同方向拖放在目标前后插入同级窗格。两个等宽窗格再横向拆分时形成三等列。已有自定义宽度时，原窗格按原比例让出新列。垂直于当前排列方向拖放时，在目标位置建立子分组。移动同组内的整个窗格时保留其尺寸。 |
| 调节窗格 | 拖动窗格分隔线，或聚焦后按相应方向键调节。Home 和 End 到达两端可用大小。每个窗格最小为 128×112 px，嵌套分屏会合并计算。窗口缩到无法容纳已有窗格时按最小尺寸比例分配，窗口扩大后恢复原比例。 |
| 等待、空数据、失败 | 复用 `StatusMessage`。等待和空数据用次要文字及 `role="status"`，失败用错误色及 `role="alert"`，允许复制错误信息。提示靠近发起操作的区域，例如设置保存失败时在对应分组提示。等待期间禁用可能重复触发的操作。 |

侧栏分隔条支持方向键以 16px 调宽，Home / End 可直接定位到最窄或最宽。

## 后续开发规划与验收

每份涉及界面的功能计划应回答下面与改动有关的问题，答案可直接作为验收场景。

- **入口在哪里？** 写明所属分类、侧栏名称和标签标题。新增业务视图通过 `src/features/**/view.tsx` 导出 `workspaceView` 注册，复用工作台的打开、关闭和分屏行为。新增文案同步中英文资源。
- **用户会遇到哪些状态？** 描述触发条件、可见反馈和下一步操作。例如题库查询成功但返回零条时显示空结果，查询失败时显示可复制的错误；两种情况都保留当前题库标签。
- **主题和输入方式如何验收？** 在浅色、深色下检查文字、图标与选中态，切换“跟随系统”检查主题响应。只用键盘走一遍新增入口和主要操作，核对可访问名称及焦点位置。
- **采用哪种视觉和动效规则？** 写明复用的页面或控件、颜色变量的定义位置，以及哪个动作触发哪项过渡。例如新增设置分组沿用二级侧栏的选中态和标签页的进入效果。开启“减少动态效果”后，焦点仍清晰可见。
- **放进窄窗格后是否可用？** 用长标题、收起侧栏、标签溢出和双窗格检查截断、滚动与活动标识。涉及编辑的视图，输入一段草稿后切换标签、移到另一窗格，再核对内容。

需要新增语义色、顶层分类或交互模式时，在同一份功能计划中说明现有规则覆盖不到的场景，列出受影响的视图和验收方式。采纳后同步更新本约定。
