# OI-table 全局界面与首页工作台设计约定

主窗口中的工作台、设置页和新增业务视图统一采用**紧凑、平面、分区清晰的桌面工具界面**。下文的视觉、主题和动效规则适用于应用界面，三栏布局和标签行为适用于首页工作台。

## 全局视觉风格

- **用布局表达层级。** 窗口用连续的底色划分导航和内容，同一面板内用标题、对齐和留白分组，相邻窗格用 1px 分隔线。题库列表适合用紧凑的行，设置项适合用标签与控件对齐的表单行。大面积渐变、投影和逐项卡片化都不作为常规界面样式。
- **形状与任务相配。** 窗格、标签栏和导航轨保持直边，让可拼接的区域自然相接。局部控件沿用小圆角，例如标签关闭按钮 3px、编辑框 4px、设置表单控件 5px、上下文菜单 6px。图标复用单色 `Icon`，通过 `currentColor` 与文字同步反馈。
- **让操作位置一眼可辨。** 大面积保持中性色，强调色集中用于当前项、焦点窗格和拖放目标。选中同时配底线、侧线或选中底色，键盘焦点保留独立轮廓。产品插画可以使用渐变与多色，常规控件沿用语义色。
- **按阅读任务分配空间。** 工具栏和导航保持紧凑，正文与表单留出阅读间距。界面沿用系统无衬线字体，代码编辑区使用等宽字体。新增页面先复用同类页面的标题、行高和间距，具体数值见下文。

## 全局动效

动效用来说明哪一项发生了变化、内容移到了哪里。按下和悬停只改变控件本身，切换面板只过渡进入的内容，拖动时位置跟随指针。新组件按下表选择最接近的场景，并显式列出参与过渡的 CSS 属性，避免 `transition: all`、弹跳、过冲和循环装饰动画。

| 使用场景 | 应采用的效果 | 时长与缓动 |
| --- | --- | --- |
| 按下、悬停 | 按下改变底色，松开回到悬停态。上下文菜单项按下 45ms、悬停 90ms。 | 短反馈用 `ease-out`。工作台导航和标签沿用所在区域的 180ms 过渡。 |
| 打开上下文菜单 | 整个菜单从 `scale(0.96)` 到原尺寸，菜单项立即可操作。 | 125ms，`cubic-bezier(0.2, 0.75, 0.25, 1)` |
| 工作台切换与布局 | 展开或收起侧栏时过渡列宽，窗格重排时过渡位置和尺寸。切换标签时，进入的面板透明度从 0.5 到 1。 | 复用 `--workspace-motion`，即 180ms，`cubic-bezier(0.2, 0.75, 0.25, 1)` |
| 标签改变顺序 | 相邻标签沿横轴从旧位置移到新位置，让用户看清落点。 | 150ms，`ease-out` |
| 拖动调宽、减少动态效果 | 拖动侧栏时直接更新宽度。系统启用减少动态效果时直接呈现最终位置、选中标记和焦点。 | 持续调宽时关闭列宽过渡。减少动态效果时工作台令牌取 `0ms linear`，右键菜单仅在 `prefers-reduced-motion: no-preference` 下开启动效，JS 标签重排也检查系统偏好。 |

目前 `--workspace-motion` 定义在 `.workbench` 内。新窗口采用表中同类场景的参数；需要跨窗口共用的动效变量应定义在 `:root`，组件内保留减少动态效果的处理。

## 布局与信息层级

| 区域 | 职责与基线 |
| --- | --- |
| 标题栏 | 高 32px，承载窗口标题、侧栏开关和窗口控制。窗口级操作放在这里，页面操作留在所属视图。 |
| 导航轨 | 固定宽 52px。题库、归档、收藏、提交记录、设置从上到下排列，使用 24px 图标，按钮至少高 50px。 |
| 侧栏 | 展示当前分类的分组和视图入口。默认宽 200px，可收起或调宽，上限取 420px 与工作台宽度 45% 中的较小值。常规下限为 128px，极窄时随上限收缩。分组每级缩进 12px，最小行高取 `--sidebar-row-height`（默认 26px）。 |
| 内容区 | 占满剩余空间。选中侧栏入口后打开标签，再次打开同一视图时定位到已有标签。每个窗格都有自己的 38px 标签栏，内容独立滚动。 |

初始进入时，题库侧栏展开，内容区居中显示透明背景的产品插画，最大宽度 640px。关闭最后一个标签也回到这里。插画中的淡紫、薄荷绿用于描绘题库和编辑场景。业务视图已经打开但尚无数据时，在视图标题下说明原因，例如“尚未接入题库数据。”，保留标签和页面上下文。

点击「设置」切换到对应的二级侧栏。外观、编辑器、运行与调试、数据与诊断各自打开一个工作区标签，再次点击同一入口会激活已有标签。设置页从窗格左侧排布表单，沿用工作区的切换动效、关闭、拖动和分屏操作。

「设置 → 外观 → 界面语言」默认跟随系统，也可选择简体中文或 English。切换后保留已打开的标签与编辑内容。

设置通过 `update_settings` 发送本次修改的键值，由 Rust 合并写入 `settings.json` 并通知其他窗口。后端对注册了规则的键进行校验，缺失或无效时使用该键的默认值。界面以 `get_settings` 返回的值为准。

## 主题配色与自定义

**切换明暗**使用设置里的“跟随系统 / 浅色 / 深色”。窗口把设置写到根元素的 `data-theme`，由 `color-scheme` 决定使用 `light-dark(浅色, 深色)` 中的哪一个值。**自定义配色**目前通过修改样式源码完成。下表给出默认值，后面的修改入口说明各变量实际影响哪些区域。

| 用途 | CSS 变量 | 浅色 | 深色 |
| --- | --- | --- | --- |
| 内容、活动标签底色 | `--window-background` | `#fff` | `#161b24` |
| 标题栏、导航轨、标签栏底色 | `--navigation-background` | `#eceff2` | `#1b2028` |
| 侧栏底色 | `--sidebar-background` | `#f7f8f9` | `#252b35` |
| 正文和主要图标 | `--text-color` | `#1b2534` | `#edf2f8` |
| 次要文字、未选标签、普通状态提示 | `--muted-color` | `#526070` | `#aab8c9` |
| 侧栏选中文字、焦点窗格下划线、拖放指示 | `--accent-color` | `#235a78` | `#93c8e4` |
| 导航悬停底色 | `--navigation-hover` | `#e8ebef` | `#2a313c` |
| 侧栏选中底色 | `--navigation-selected` | `#e2e9ed` | `#303d48` |
| 标题栏按钮、标签和菜单项悬停底色 | `--title-bar-hover` | `#dfe5ed` | `#344155` |
| 错误文字 | `--error-color` | `#a1241c` | `#ff9a90` |

### 按修改目标找入口

| 想改什么 | 修改位置和变量 | 会一起变化的部分 |
| --- | --- | --- |
| 整个应用的底色与文字 | [基础样式](../src/app.css) 的 `:root`。用 `--window-background` 改内容底色，`--navigation-background` 改导航底色，`--sidebar-background` 改工作台二级侧栏底色。用 `--text-color`、`--muted-color`、`--error-color` 分别改正文、次要信息和错误。 | 设置页与其他工作区页面使用同一内容底色。普通图标继承文字色，菜单边界取正文色的 15%。 |
| 窗口标题与关闭按钮 | 同一 `:root` 下的 `--title-bar-color` 默认引用正文色。`--title-bar-hover` 控制普通悬停，`--title-bar-close-hover` 与 `--title-bar-close-color` 控制关闭按钮悬停的底色和图标，默认红底白字。 | 普通悬停色还影响标签、上下文菜单项和设置按钮。业务错误文字由独立的 `--error-color` 控制。 |
| 侧栏选中与悬停 | 二级侧栏使用 `:root` 的 `--accent-color`、`--navigation-selected` 和 `--navigation-hover`。 | 工作台通过 `--workbench-accent` 引用同一强调色，分屏预览混入 18% 强调色。导航轨当前分类使用自己的显式色值。 |
| 表单控件与工作台边界 | [基础样式](../src/app.css) 的 `--control-border` 和[工作台样式](../src/workspace/workbench.css) 的 `--workbench-border`。 | [公共表单控件](../src/shared/ui/Fields.tsx)统一绘制外框、下拉面板和数字步进按钮。控件边界默认取正文色的 21%，工作台边界默认取 15%。 |
| 表单控件尺寸 | [基础样式](../src/app.css) 的 `--control-width` 和 `--control-height`。 | 输入框和下拉按钮默认宽 160px、高 36px，编辑时维持原尺寸。 |
| 滚动条 | [共用滚动样式](../src/shared/ui/scrollbar.css) 的 `--scrollbar-line` 和 `--scrollbar-hit-padding`。 | 2px 滑块，上下或左右各加 3px 操作区域，浮在内容边缘。普通滚动区域复用 [ScrollArea](../src/shared/ui/ScrollArea.tsx)，标签栏和文本域通过同一滚动条接入原有滚动容器。 |

将侧栏与工作区的蓝色强调改为青绿色时，可在 [基础样式](../src/app.css) 的 `:root` 调整这两个共享变量。

```css
:root {
  --accent-color: light-dark(#17645b, #86d8c9);
  --navigation-selected: light-dark(#e0efeb, #293e3b);
}
```

若同时调整导航轨的当前分类，可修改 `.workspace-rail button[aria-pressed="true"]` 的文字色。该按钮的选中底色会混入 18% 的 `currentColor`。修改后在浅色和深色下检查首页与设置页的选中态、活动标签、拖放预览和键盘焦点。

### 排版与间距

「设置 → 外观」提供系统默认、微软雅黑和衬线字体，界面基准字号可设为 12–20 px，默认 16px。系统默认字体沿用 Segoe UI、Microsoft YaHei 和系统无衬线字体。字号通过 `--ui-font-size` 按比例调整界面文字。默认字号下，工作台页面与设置分组的标题均为 20px，侧栏文字 13px，标签标题 12px。代码编辑区使用独立的等宽字体。页面内边距用 `--space-lg`（24px），内容分隔用 `--space-md`（16px），图文间距用 `--space-sm`（8px）。首页二级侧栏和设置分组入口复用 15px 的 `Icon`，图标随文字颜色变化。长标签单行省略，保留完整名称供悬停和辅助技术读取。

## 状态与交互

| 场景 | 约定与判断依据 |
| --- | --- |
| 当前分类 | 点击导航轨按钮会展开对应侧栏。侧栏可见时，该分类设为 `aria-pressed="true"`，图标使用浅色主题的 `#103d66` 或深色主题的 `#b7e8ff`，底色在导航背景上混入 18% 图标色。收起侧栏后取消按下态。 |
| 分组与入口 | 分组用字重 600 和箭头方向表达展开状态，并同步 `aria-expanded`。侧栏用 `aria-current` 标记最近点选的入口，以选中底色配强调色文字。直接切换标签时，侧栏仍保留上次点选位置。 |
| 活动标签与焦点窗格 | 每个窗格的活动标签都使用内容底色、正文色和 2px 底线。只有当前操作窗格的底线使用强调色，其他窗格使用边界色。将键盘焦点移入具体控件时，还应能看到该控件自己的焦点轮廓。 |
| 标签操作 | 左右方向键切换，Home / End 定位首尾，Delete 关闭，Shift + F10 打开操作菜单。关闭按钮在选中、悬停或焦点进入标签时出现，无悬停设备上常显。菜单中无可执行效果的操作保留位置并禁用。 |
| 拖动与分屏 | 被拖标签降至 55% 不透明度。标签之间用 2px 插入线，移入目标窗格用内描边，分屏用覆盖预计区域的半透明预览。移动已打开的视图时保留草稿和滚动位置。 |
| 等待、空数据、失败 | 复用 `StatusMessage`。等待和空数据用次要文字及 `role="status"`，失败用错误色及 `role="alert"`，允许复制错误信息。提示靠近发起操作的区域，例如设置保存失败时在对应分组提示。等待期间禁用可能重复触发的操作。 |

侧栏分隔条支持方向键以 16px 调宽，Home / End 可直接定位到最窄或最宽。

## 后续开发规划与验收

每份涉及界面的功能计划应回答下面与改动有关的问题，答案可直接作为验收场景。

- **入口在哪里？** 写明所属分类、侧栏名称和标签标题。新增业务视图通过 `src/features/**/view.tsx` 导出 `workspaceView` 注册，复用工作台的打开、关闭和分屏行为。新增文案同步中英文资源。
- **用户会遇到哪些状态？** 描述触发条件、可见反馈和下一步操作。例如题库查询成功但返回零条时显示空结果，查询失败时显示可复制的错误；两种情况都保留当前题库标签。
- **主题和输入方式如何验收？** 在浅色、深色下检查文字、图标与选中态，切换“跟随系统”检查主题响应。只用键盘走一遍新增入口和主要操作，核对可访问名称及焦点位置。
- **采用哪种视觉和动效规则？** 写明复用的页面或控件、颜色变量的定义位置，以及哪个动作触发哪项过渡。例如新增设置分组沿用二级侧栏的选中态和标签页的进入效果。开启“减少动态效果”后，焦点仍清晰可见。
- **放进窄窗格后是否可用？** 用长标题、收起侧栏、标签溢出和双窗格检查截断、滚动与活动标识。涉及编辑的视图，输入一段草稿后切换标签、移到另一窗格，再核对内容。

需要新增语义色、顶层分类或交互模式时，在同一份功能计划中说明现有规则覆盖不到的场景，列出受影响的视图和验收方式。采纳后同步更新本约定。
